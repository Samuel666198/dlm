## B. 明确不做（记录理由，避免以后重提）

- **裸 WebSocket 固定端口**（IDM 用 `ws://127.0.0.1:1001`）：无鉴权，本机任何进程可冒充。dlm 继续 native messaging + token HTTP。
- **`proxy` / `management` / 全站 `cookies` 权限**：权限面过大，审核与信任成本高。
- **视频站点解析**（YouTube 等）：维护与合规风险高。
- **压缩混淆单文件**：无法静态检查、无法定位。
