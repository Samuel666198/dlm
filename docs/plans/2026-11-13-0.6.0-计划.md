## 阶段 0 · 地基（先做，1 天）

1. `dlm --json`：一行一个任务的 JSON；错误同形；`--quiet` 与 `--json` 可共存
2. 错误码枚举固定：`BAD_URL` / `NO_SUCH_DIR` / `DISK_FULL` / `DUPLICATE` / `APPROVAL_EXPIRED` / `APPROVAL_MISMATCH` / `NOT_FOUND` / `BUSY` / `INTERNAL`
- 判据：`--json` 的输出有快照测试；失败路径也走 JSON

## 阶段 1 · 主界面改版（2 天）

- 顶层只留 `＋新建▾` / 搜索（Ctrl K）/ `⚙` / `⋯`
- `＋新建▾` = 单链接 / 批量粘贴 / 站点抓取
- **上下文动作条**：仅选中时出现（继续 / 暂停 / 删除）
- `全部暂停` / `删除全部` 收进 `⋯`，删除全部二次确认
- 状态栏升级为活动条：在跑数 / 合计速度 / **限速可点改**
- 表格加「速度迷你曲线」列（先占位，阶段 3 接真数据）
- 判据：现有 GUI 测试全绿；新增「选中才显示动作条」的纯函数测试

## 阶段 2 · 设置页改版（2 天）

- 左侧分类：下载 / 连接与速度 / 限速计划 / 代理 / **Agent 接入** / 界面 / 高级
- 右侧分组卡片，每行三列：标题 + 一句解释 + 控件
- 顶部「搜索设置项」
- 新面板「Agent 接入」：CLI 命令复制（现在就可用）/ MCP 配置复制（未装则置灰）/ 确认开关
- 判据：每个设置项都有归属分类，无「其它」兜底

## 阶段 3 · 站点抓取窗口改版（1.5 天）

- 按 `grab-ui.html`：起始页 / 范围 / 模板 / 扫描进度 / 清单 / 跳过折叠 / 底部入队
- 清单列：勾选 · 文件名+来源页 · 类型 · 来自 · 大小
- 重复项显示「已去重」且不可勾选
- 模板：**按站点记**（`example.com` 记住自己的深度与通配）
- 判据：`grab` 模块新增模板存取测试；窗口行为测试覆盖「无勾选时入队按钮禁用」

## 阶段 4 · 特色功能（按顺序，每项一天）

1. **夜间批次**：限速窗口 + 队列编排 + 「跑完关机」串成一个开关
2. **规则引擎**：`URL 匹配 → 目录 / 连接数 / 改名 / 限速`，命中即用
3. **命令面板** `Ctrl K`：英文命令 + 中文解释
4. **卡顿诊断**：每任务速度曲线 + 「重试 N 次 / 卡住 M 秒」标注

## 阶段 5 · Agent 接入闭环（2 天）

1. GUI 本地控制口（`127.0.0.1` + token）
2. `dlm-mcp`：`add_download` / `confirm_download` / `list_tasks` / `pause_task` / `resume_task` / `remove_task` / `set_speed_limit` / `grab_site` / `confirm_grab`
3. 票据规则：一次性、5 分钟过期、绑定 URL+落点
- 判据：票据过期与参数不匹配各有测试；控制口拒绝无 token 请求
