# 0.5.0 计划（2026-11-13）

> 三件事都由用户点名进这一版：**限速计划 → 代理支持 → 托盘气泡**。
> 顺序按"影响面从小到大"排：限速只碰调度、代理碰传输层、气泡碰 Win32。
> 纪律不变：每阶段一提交、每阶段跑 `gates.ps1`（lib 只增不减，当前 420）；打包与发布等用户点头。

## 1. 限速计划（按时间段自动切速度）

**要解决的事**：白天限速别抢带宽，半夜放开跑。现在只有一个全局"最大速度"。

- 设置模型新增 `speed_windows: Vec<SpeedWindow>`，每项 `{ start_minute, end_minute, kibps }`
- 纯函数 `rate_at(minute_of_day, windows) -> Option<u32>`：落在哪个窗口就用哪个值；都不命中用全局值；跨零点窗口（22:00–06:00）必须正确
- 生效点：`RuntimeTuning` 增加 `max_speed_kib` 的**动态取值**，runner 每次派发前算一次，不需要重启任务
- 界面：设置页「限速计划」小节，最多 4 条，带"现在生效值"提示
- 判据：`rate_at` 全部边界有测试（整点、跨零点、窗口重叠取第一条、空表回全局）

## 2. 代理支持（HTTP / SOCKS5）

**要解决的事**：有些网络只能走代理。

- 设置新增 `proxy: String`（空 = 直连），形如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080`
- 纯函数 `parse_proxy(&str) -> Result<Option<ProxySpec>, String>`：只认这三种 scheme，缺端口报错，带用户名密码的 URL 允许但**不进日志**
- 接线：`probe::build_client` / `fetch` 的 client 构造统一走 `apply_proxy`；HLS 与抓取共用同一处
- 界面：设置页「代理」一行 + 「测试连接」按钮（只做一次 GET 到 `https://www.gstatic.com/generate_204`，超时 5s）
- 判据：`parse_proxy` 表驱动测试；"代理串不带密码进日志"有断言；直连时空串不改变任何行为

## 3. 托盘气泡（收进托盘时说一声）

**要解决的事**：点 X 后窗口消失、进程还在，用户不知道"它还在下"。

- `tray-icon` 0.21 没有 balloon 能力 → 直接调 Win32：
  `Shell_NotifyIcon(NIM_MODIFY, NOTIFYICONDATAW{ NIF_INFO, szInfo, szInfoTitle, dwInfoFlags })`
- 时机：`hide_instead_of_quit()` 返回 true 且真的隐藏成功时，弹一次；同一分钟内不重复
- 非 Windows 平台：空实现（`#[cfg(windows)]` 包住），不留编译分支
- 判据：`should_notify(now, last_notified)` 纯函数测试；气泡文案固定为「dlm 仍在下载，双击托盘图标可恢复窗口」

## 风险与回退

| 风险 | 回退 |
|---|---|
| 限速窗口跨零点算错 | `rate_at` 边界测试先行；算不出就回全局值 |
| 代理配置把直连也弄坏 | 空串 = 直连；解析失败**不清空**已保存配置，只报错 |
| Win32 结构体布局错 | 只在隐藏成功后调用；失败只记 stderr，不影响下载与退出 |
| 托盘句柄生命周期 | 复用现有 `Tray`；不新建第二个图标 |

## 明确不做

- 系统级代理设置（我们只改自己的 client，不碰 `WinINET`/注册表）
- PAC 脚本与自动代理发现
- 按任务单独设代理（0.6.0 再谈）
