# 第一部分：0.6.1 补丁（四个缺陷）

四条都是我自己写错的，判据明确、改动小。**不动布局、不加功能。**

## 1. `Ctrl K` 打不开命令面板

**根因**：`app/palette.rs` 里 `let mut close = false;` 然后 `Window::open(&mut close)`。
egui 把这个 `false` 当成"窗口已关闭"，每帧跳过绘制。

**改法**：去掉 `.open(&mut close)`（面板没有标题栏，本来也没有关闭按钮），
Esc 关闭沿用已有的 `close = true` 分支。

**判据**：
- 现有 `shortcut_for` 用例不变（映射本来就对）；
- **新增**整帧用例：喂一个 `Ctrl+K` 的 `Event::Key`，`palette_open` 必须为真，
  且该帧 **真的画出了面板**（用 `ctx.memory` 里窗口是否存在的探针，或渲染后断言 shapes 非空）。
- 注意：手造 `Event::Key` 时 egui 0.37 的 `input.modifiers` 不会跟着变（实测），
  所以这一条要**直接调 `handle_shortcuts` 的路径**或绕开修饰键读取，否则用例假红。

## 2. `×` 不收起托盘

**根因**：`app::hide_on_close(close_to_tray, tray_available, busy) = 三者与`。
空闲时 `busy=false` ⇒ 直接退出，与设置项「关闭窗口时收进托盘」的字面意思相反。

**改法**：判据改为 `close_to_tray && tray_available`；`busy` 参数删掉。
同时确认托盘菜单有「退出」（没有就补，否则开关打开后关不掉）。

**判据**：
- 改 `hide_on_close` 的用例：空闲 + 开关开 ⇒ `true`；
- 开关关 ⇒ `false`（无论忙闲）；
- 无托盘 ⇒ `false`（不能把窗口藏了却无处可点）。

## 3. 长报错 / 长 URL 溢出窗口

**根因**：`app/drawer.rs` 把日志与 URL 用 `ui.horizontal(...)` 包着放 `ui.label`，
horizontal 的横轴是无限宽 ⇒ 永不换行 ⇒ 把窗口撑变形。

**改法**：
- 日志：`ScrollArea::vertical().max_height(...)` + `Label::new(...).wrap()`（保留等宽字体）；
- URL：单行省略，悬停显示全文（`on_hover_text`）；
- 落点同理。

**判据**：整帧渲染一条 400 字的单行日志后，窗口 `Rect` 宽度不超过设定宽度。

## 4. 详情两个关闭按钮

**根因**：窗口标题栏自带 `×`，`drawer_body` 里又画了一个 `small_button("×")`。

**改法**：删掉正文里那个，只留标题栏。

**判据**：`drawer_body` 返回的 actions 不再有"点击正文关闭"入口；渲染用例照旧通过。

**提交**：`fix(ui): 0.6.1 四个缺陷（面板不显示 / 关窗不收托盘 / 长文本溢出 / 双关闭）`

# 第二部分：0.7.0 界面改版

八步，每步独立可提交、可回退。**顺序按依赖排**，不是按重要性。

## 步骤 1：图标系统（24 个）

先做图标，因为后面每一步都要用。

- `app/icons.rs` 扩到 24 个：入口 4、任务状态 4、分类 7、动作 9；
- 全部 `draw_icon(painter, rect, kind, color)` 自绘，**不用 Unicode 字符**；
- 分类图标与 `queue::category_for` 共用映射（`icons::for_category`）；
- 状态图标带颜色语义由调用处传色（进行中=ACCENT、已完成=OK、失败=BAD）。

**判据**：每个图标有渲染用例（画到离屏 painter 不 panic）；分类映射与
`category_for` 的七个分支一一对应（穷举 match 保证）。

## 步骤 2：壳（顶栏 + 左栏 + 窗口级状态栏）

- 顶栏：品牌位（**Download Manager** 粗体）+ 搜索框（560 上限、26px 左距、半透明、Ctrl K 内嵌）+ 设置/更多；
- 左栏：顶部面板图标（收起）+ 三入口（新建任务 / 站点抓取 / 下载列表）+ 任务四项 + 分类七项，全部带图标；
- 收起态：52px 图标条、分隔线代替组标题、每项 `on_hover_text`；
- 状态栏移到窗口底部（`App::status_bar`）。

**判据**：收起/展开各渲染一帧；状态栏位置在收起前后一致（同一 y）。

## 步骤 3：列表（复选框 + 批量 + 右键菜单）

- 列表首列复选框；表头复选框全选/全不选；
- 多选集合 `HashSet<String>`；`Ctrl+单击` 追加、`Shift+单击` 连选；
- 右键菜单：继续 / 暂停 / 打开文件 / 打开文件夹 / 复制链接 / 删除；
- 批量条：仅多选时出现，显示已选数量与批量动作。

**判据**：选择集合的纯函数用例（单击、Ctrl、Shift、全选、删除后清理）；
`Delete`/`Space` 快捷键改为作用于多选集合。

## 步骤 4：详情右栏化

- 从 `egui::Window` 改成主区右侧固定栏（330px），单关闭；
- 日志换行滚动（沿用 0.6.1 的做法）；
- 列表可用宽度随右栏出现/消失调整（`RIGHT_SIDE_W` 一类常量一起改）。

**判据**：右栏开关时列表列宽不溢出；长日志不撑宽。

## 步骤 5：命令面板接线

- 面板本体已在 0.6.0 写好，只在 0.6.1 修了显示 bug；
- 本步补：命令表按设计稿分组（搜索/新建/任务/跳转），中英双列，快捷键右挂；
- 新入口：点搜索框也开面板。

**判据**：命令数量与分组数量和稿子一致；每条命令执行后状态变化正确。

## 步骤 6：设置页（八分类 + 固定尺寸 + 文案）

- `settings_spec::Category` 从 7 扩到 8（新增「浏览器扩展」）；
- 窗口固定 720×440，内容内部滚动；
- 界面页新增：语言 / 主题 / 密度 / 启动收起侧栏 / 关窗收托盘 / 首次提示；
- Agent 接入页新增：dlm-mcp 获取与版本；
- 浏览器扩展页：安装状态、管理、更新（诚实文案）；
- 高级页新增「版本」卡（四项 + 复制）；
- 全部 hint 文案书面化。

**判据**：`every_settings_field_has_exactly_one_spec` 与分类用例更新后全绿；
每页渲染用例覆盖；固定尺寸断言（切分类前后窗口矩形相同）。

## 步骤 7：抓取页三步

- 步骤条（地址 → 范围 → 清单）+ 左表单右模板卡；
- 扫描后原地变结果表。

**判据**：三步状态机用例；扫描中/结果/空结果三态渲染。

## 步骤 8：明暗主题

- `theme.rs` 增加深色 token 一套（15 个常量），`theme::apply(ctx, mode)`；
- `Settings.theme`：跟随系统 / 浅色 / 深色；
- 逐屏核对对比度（尤其进度条 track/fill、语义色）。

**判据**：每屏在两种主题下各渲染一帧；关键对比度用固定值断言（不靠肉眼）。

### 已知待办（本轮发现的，下一轮先做）

**更正：自绘控件是能被点中的。** 早先记的"设置分类点不动"是我用了**过期 ref** 造成的误判 ——
复测后侧栏「失败」「下载」等自绘项 `InvokePattern.Invoke` 都正常生效。

真实结论分两种角色：
- `Role::Button` + `Invoke` → egui 能接住（自绘也行，只要 `Sense::click` + `widget_info`）；
- `Role::CheckBox` 收到的是 `LegacyIAccessible.DoDefaultAction` → **只有真 `Checkbox` 控件才认**，
  自绘版"树里有、点不动"。勾选框因此改成了真控件。

另：同一窗口内多个控件同名会让自动化认不出（`AMBIGUOUS_TARGET`），无障碍名必须带区分信息
（勾选框已改成「勾选 <任务名>」）。

> 无障碍那一条原本不在计划里。做步骤 4 出证据时发现：headless 禁物理点击、行又不在
> 无障碍树里 ⇒ **没有任何入口能选中一行**。止血方案是加调试开关，最优方案是把树接起来 ——
> 选了后者，顺带侧栏项也接上了（读屏软件从此能读列表）。
