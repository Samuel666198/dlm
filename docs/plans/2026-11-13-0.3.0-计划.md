## 阶段 2 · 扩展 downloads 接管（核心）✅ 已完成

### 2a 权限与判定（纯逻辑，可测）
- `manifest.json`：加 `downloads` 权限（不加 `downloads.ui`/`shelf`）。
- 新文件 `browser/extension/takeover.js`（被 `background.js` import，若 MV3 支持 `import`；否则内联到 background 并单独导出纯函数供测试）。
- 纯函数（可被 `node --test` 直接跑）：
  - `extAllowed(filename, whitelist) -> bool`
  - `siteAllowed(url, blocklist) -> bool`（复用 A3 逻辑）
  - `shouldTakeover(item, settings) -> {take: bool, reason: string}`
- 默认设置：`enabled=false`、`whitelist=[zip,7z,rar,iso,exe,msi,mp4,mkv,flac]`、`minBytes=1MiB`。

### 2b 接管流程（先 ack 后 cancel）
- `chrome.downloads.onCreated` → `shouldTakeover` 命中 → 生成 `request_id` → 经 port 发 `{op:"download", request_id, url, referer, cookie?}`。
- 收到 `accepted` 且 `request_id` 匹配且 `ok` → `chrome.downloads.cancel(id)`；2 秒无回执 → 什么都不做，记 `lastTakeover = {reason:"no-ack"}`。
- 仅在 `item.bytesReceived === 0` 且 `item.state === "in_progress"` 时取消。
- 失败路径（host error / 端口断）：不取消。

### 2c 选项页
- `options.html` 扩为两节：站点规则（已存在）、接管设置（开关/白名单/最小体积）。
- 保存到 `chrome.storage.local`，键：`takeover`。

### 2d 验收
- 手工：开接管 → 点一个 zip 附件 → 浏览器下载消失、dlm 出现任务；关接管 → 行为恢复。
- 反向：host 停掉时点 zip → 浏览器下载**必须保留**、扩展记录 no-ack。
- 静态：`node --check` 三个 JS；`check-extension-static.mjs` 通过。

## 阶段 3 · MIME → 类型表（宿主侧）

- 新模块 `src/mime.rs`：`category_for_content_type(&str) -> Category`，表覆盖 mp4/mkv/zip/7z/rar/pdf/mp3/flac/exe/msi/iso/torrent。
- 接进队列：`queue::add` 增加可选 `content_type`，`category_for` 优先用 MIME，其次扩展名。
- 测试：表驱动（每个 MIME 一条），未知类型回 `Other`；与扩展白名单**不共享代码**，各自独立（JS 侧只按扩展名）。

## 阶段 4 · `Content-Disposition` 文件名

- `probe`/`fetch` 侧解析：`filename*`（RFC 5987）优先 → `filename=`（去引号）→ 回退 URL 尾段。
- 只在**缺少用户给定 name** 时采用；不得覆盖用户显式命名（E1 模板仍最高优先）。
- 测试：编码/引号/路径穿越（`..\\`、`/`、控制字符）必须被拒并回退。

## 阶段 5 · 视频嗅探增强（路线 1，不做站点解析）

- 扩展嗅探：增加 `application/dash+xml`（MPD）与 `application/vnd.apple.mpegurl`，识别 `.mpd` 查询串变体。
- 宿主：HLS 已支持；DASH 仅登记"可交给外部工具"，**不内置下载器**（避免半成品）。
- 判据：嗅探只认响应头/URL 形状，不执行页面 JS，不破解签名。

## 阶段 6 · 站点抓取 Grabber（0.4.0 模块，先出设计再实现）

- 输入：起始 URL、深度 1–3、同域开关、包含/排除通配、最大页数/文件数/总字节。
- 流程：抓页面 → 提取 `<a href>`/`<img src>`/`<video src>` → 过滤 → **先出清单**（不下载）→ 用户勾选 → 入队。
- 礼貌：读 `robots.txt`、单域并发 1、可配延迟。
- 判据：链接提取与通配匹配是纯函数；"只列清单"独立可测；不跟随 `mailto:`/`javascript:`。

## 风险与回退

| 风险 | 回退 |
|---|---|
| 接管误判导致文件没下成 | 默认关；命中先 ack 后 cancel；任何异常不 cancel；站点黑名单可关 |
| 旧扩展/新宿主不兼容 | 新字段全部可选；未知 op 忽略 |
| MIME 表与扩展白名单漂移 | 两处各自测试，文档写明"白名单只按扩展名" |
| Grabber 拖垮站点 | 页数/文件数/字节三重上限 + 单域并发 1 + 延迟 |
