**不做**：IDM 的视频站点解析（YouTube 等）—— 维护成本与合规风险都高，且最容易被平台改版打断。

## 每项的判据（都要落成测试）

- F1 搜索：`matches_search` 纯函数；空串全通过；大小写不敏感；名字与 URL 都参与；与状态/分类筛选是**与**关系。
- F2 快捷键：只在主窗口无输入焦点时生效（搜索框里按 `Del` 不许删任务）；`Ctrl+F` 聚焦搜索框。
- F3 拖拽篮：拖入非 URL 文本不建任务；拖入 URL 走与 `/api/add` 同一条校验。
- E1/E2：模板渲染纯函数（未知变量原样保留）；同名冲突策略三个分支各一条用例；**已存在任务不被改写**。
- E3：扫描命令拼装（路径带空格要引号）；扫描失败 → 任务仍 `done`，只多一条日志。
- A1/A2/A3：扩展静态检查（`check-extension-static.mjs`）必须仍然绿；host 消息格式不破坏 0.2.12 的 ping/pong。

## 门禁

## 风险

- A 组会碰扩展（浏览器里要重新「重新加载」才能生效）——每批都提醒用户一次。
- E3 依赖 Windows Defender 的 `MpCmdRun.exe` 路径（随 Defender 平台版本变化），找不到就只记日志，不报错。
- 版本号：本批全部完成后 `gui::RELEASE` 直接跳 **0.2.0**；中途每批仍按现有规则各自 +1（0.1.4、0.1.5…）。
