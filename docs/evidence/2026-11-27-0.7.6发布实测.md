## 验证（都是重新取回来的，不是读本地缓存）

1. **重新下载两个 zip 再算 sha256**：与本地构建值逐位相同（见上表）。
2. **`gh api repos/…/releases/latest`** ⇒ `v0.7.6`。
3. **`contents API` 读 `latest.json`** ⇒ `release 0.7.6 / extension 0.2.18`。
4. **`raw.githubusercontent.com` 直读**：推送后约 **4 分半**仍是 `0.7.5`（CDN 缓存），
   14:51:29Z 翻面为 `0.7.6`。**应用读的就是这个地址**（`src/gui/mod.rs:69`），
   所以"发完立刻查还是旧版"是缓存延迟，不是没生效。
