# C0–C3 产品层证据（2026-10-22）

**C0 裁定**：本地 Web UI，零新 crate。理由：eframe/Tauri/Win32 要么破"6 个直接依赖"、要么引入 webview/构建链；
本地 Web UI 用 `std::net` 手写 HTTP，复用浏览器验收通道。代价：没有原生窗口。

## 1. C1 队列

- `src/queue.rs`：任务（id/url/name/referer/status/pid/exit/log/start_at/progress）、
  `QueueStore` 原子写、`recover_running`（重启 running→paused）、从 `.dlm.json` 读进度。
- 状态：`queued/running/paused/done/failed`；暂停 = kill 子进程（断点保留），恢复 = 重新入队。
- **不存 Cookie**；认证下载继续走 B2 的一任务一进程入口。
- `start_at`（Unix 秒）由 C1 runner 比较；A3b 移入的计划任务由它接住。

## 2. runner + HTTP + UI

- `src/gui.rs`：500 ms actor（reap、并发、start_at、pause/resume/remove）；HTTP 只绑
  `127.0.0.1`，所有路径要求 `?t=<token>`；token 默认随机，测试可 `--token`。
- API：`/api/tasks`、`/api/add`、`/api/pause|resume|remove`、`/api/log`（只读 log 目录、≤64 KiB 尾）。
- UI：内嵌单页；添加 URL/文件名/Referer/可选起始时间；任务列表/进度/日志/暂停/恢复/删除；
  所有数据用 `textContent`。
- `dlm-gui` 进程活着 = 调度器活着；不是 Windows 服务。
- 默认：`%LOCALAPPDATA%\dlm\queue.json`、`%USERPROFILE%\Downloads`、
  `%LOCALAPPDATA%\dlm\gui\logs`、同目录 `dlm.exe`、并发 2。

## 3. 验收

### Rust API 端到端（integration）

`gui_queue_adds_and_finishes_a_download`：

- 启动真的 `dlm-gui`（固定端口/token，临时 queue/out/log，`--dlm` 指向测试 dlm）；
- 添加 node harness `http://127.0.0.1:<port>/sz/65536`，名字 `gui.bin`；
- 轮询 `/api/tasks` 到 `done`；落盘 65536 B；job log 含"下载已完成"；
- 另一条 `start_at = now + 3600` 的任务保持 `queued`；`pause` → `paused`、`resume` → `queued`、
  `remove` → 列表消失。

## 4. 过程中修的三处

1. **GUI 测试挂死**：GUI 子进程 `stderr(Stdio::inherit())` 继承了测试的 stderr；测试失败时没人杀它，
   `tail` 等不到 EOF。改成 guard（Drop 里 kill/wait）+ stderr 写文件。
2. **remove 是异步的**：测试点完 remove 立刻查列表，抢在 runner 500 ms tick 之前；改成轮询到消失。
3. **Done 显示 `0 / ? B`**：dlm 成功后会删断点，queue 读不到 total；回退到目标文件长度，Done 时
   把 total 补齐，UI 显示 `65536 / 65536 B`。
4. **队列保存不是原子写**：`QueueStore::save` 原先在 `rename` 前先 `remove_file`，把原子替换拆成
   "删旧 + 改名"两步（崩在中间丢队列），与 spec 的"tmp → rename"不符。改成直接 `rename`
   （Windows 上会替换已存在目标）；修后四闸复跑仍全绿。

## 5. 安全/未做

- 只绑 127.0.0.1 + token；队列不存 Cookie；日志 API 只读 log 目录；UI 不用 innerHTML 插值。
- 未做：原生 GUI、Windows 服务/开机自启、队列 Cookie/认证、B3 媒体嗅探、A5 IDM 断点兼容。
- `start_at` 的任务需要 `dlm-gui` 进程一直活着；这是产品层事实。
