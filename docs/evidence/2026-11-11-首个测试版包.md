## 安装

```powershell
# 解压后在该目录
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

然后 `chrome://extensions` / `edge://extensions` → 开发者模式 → 加载已解压 →
选 `%LOCALAPPDATA%\dlm\extension`。

启动：开始菜单「dlm」，或 `%LOCALAPPDATA%\dlm\bin\dlm-gui.exe`。

## 本次打包顺手修的三处（都是包内文档/脚本，不涉产品代码）

1. **开始菜单快捷方式去掉了 `--open`**。原来带 `--open`，而 Web UI 已删除，
   那个开关会用 Edge/Chrome 再开一个 app 模式窗口，里面只有一张「dlm 现在是原生窗口」
   的说明页 —— 双击图标会弹两个窗口。第一个测试版本不该是这个体验。
2. `START-HERE.txt`、`README-PACKAGE.md` 里同样的 `--open` 指引与
   「原生 GUI 是 Web UI 的 app 模式窗口」的过时说法一并改掉。
3. `packaging/README.md` 里扩展版本号 0.2.6 → 0.2.11。

## 打包时已做的验证（不是推断）

用临时目录 + 本地 Range 服务器跑的，**没有碰 `model.safetensors`**：

| 验证 | 结果 |
|---|---|
| `dlm --version` | `dlm 0.1.0` |
| `dlm-gui --help` | 参数表完整 |
| `dlm-native-host` 空 stdin | 干净退出（符合 Native Messaging EOF 语义） |
| 3 MiB 完整下载 | 3,145,728 B，sha256 与源一致，exit 0 |
| `--max-bytes 1048576` 中断 | 落盘 1,064,960 B，exit 3，断点文件生成且内容正确（段表 `[0,1064959]`、`total_len`、`last_modified` 都在） |
| 续传 | 从 1,064,960 接到 3,145,728，sha256 与源逐字节一致，`dup 0.0%`，exit 0，断点文件自动删除 |

**结论：内核续传确实可用。** E16 那个「暂停后没有继续」是**入口缺失**，不是能力缺失。

## 建议实测顺序

按「最容易发现问题」排，每步都记下实际现象：

1. **装 + 起窗口**：开始菜单点「dlm」，确认只弹**一个**原生窗口（不是浏览器窗口）。
   关窗后看托盘图标还在不在，从托盘能不能叫回来。
2. **扩展投递**：右键一个普通文件链接 → Download with dlm。看落点、看进度。
3. **页内悬浮球**：随便开个页面，点右下角球，确认能开面板（0.2.11 刚修的）。
4. **暂停 → 继续**（E16 正主）：投一个**大文件**，在原生窗口里点「暂停」，
   再点「继续」。记：**有没有「继续」按钮**、点了之后进度是接着走还是从 0 重来。
5. **浏览器侧暂停**：在悬浮球面板里投一个大文件，点「停止」。记：停止后
   **面板里有没有任何能续的按钮**（预期：没有 —— 这就是 E16）。
6. **HLS**：找个 m3u8 页面，确认能下。记：中断后是否从头开始（预期：是，设计如此）。
7. **设置**：改「连接数」「限速」，存盘，跑一个下载。记：实际生效没有
   （预期：**没有**，`connections`/`max_speed` 仍是硬编码 8 —— 已知欠账）。
8. **自启**（可选）：`install.ps1 -Autostart`，重启后看有没有偷偷弹窗
   （预期：**会弹**，E14 未解决）。
