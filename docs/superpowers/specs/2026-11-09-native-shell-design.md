# 原生外壳设计（草稿，2026-11-09）

状态：**记录已定决策，范围待你拍板后转正式设计稿**。
本文件是讨论的落点，不是最终设计。定稿前不写产品代码。

## 一、意图

现在 `dlm-gui` 是「本地 HTTP 服务 + 用系统浏览器 `--app` 开个无地址栏窗口」，
二进制 4.75 MB、纯 Rust、没有 WebView。这条路解决了"不做 GUI 又要有界面"，
但拿不到三件事：

1. 真实窗口与**托盘**（下载器要常驻，托盘是标配）
2. **不依赖浏览器**（现在没有 Edge/Chrome 就没有界面）
3. **启动快**（现在要先起浏览器再加载页面）

三条你都要，所以这不是"以后再说"，是现在就换。

**浏览器扩展保持不变**：它是快捷入口，走 `扩展 → 宿主 → POST /api/add`。
那是一条进程间接口，与 UI 怎么画无关。HTTP 服务留在进程里继续当扩展的入口。

## 四、进程形状

```
dlm-gui.exe（单进程常驻）
├─ 主线程      winit 事件循环 + egui 绘制
├─ UI 层       直接读 Arc<Mutex<Vec<TaskView>>>
├─ HTTP 线程   只服务扩展（/api/add /api/pause /api/reveal ...）
├─ runner      队列 + 子进程（完全不动）
└─ 托盘        tray-icon + 菜单
```

`snapshot_of()` 本来就是纯函数，UI 与 HTTP 各读一份，互不阻塞。
这样 UI 不必绕一圈 HTTP 打自己的服务。

## 五、IDM 能力对账

依据 `projects/tool/idm-recon/docs/40-capability-surface.md` 与 `50-idm-capability-spec.md`。

### 已满（P0 内核 9 条）

分段调度、中点劈分、16 KiB 下限、无 Range 退化、`Accept-Encoding: identity`、
断点与段表、`--sha256` 校验、Basic 认证、POST 体、`--max-speed`。

### IDM 能力对账已落地（2026-11-09）

完整对账见 `projects/tool/idm-recon/docs/55-idm-capability-diff-2026-11-09.md`，
依据是 IDM 6.42 语言包 1,620 条界面字符串（零副作用路径），不是界面推测。

**IDM 工具条原文**（控件 ID 20376–20446）：

```
新建任务 · 继续 · 停止 · 全部停止 · 删除任务 · 删除全部
· 选项 · 计划任务 · 告诉朋友 · 隐藏细节 / 显示细节
```

**列**：`文件名`、`状态`、`大小`、`剩余时间`、`传输速度`、`描述`。

**本轮建议纳入原生重写的三项**（投入小、体感强）：

1. **剪贴板监视** — IDM `1061`：复制链接就提示下载，托盘常驻后顺手就有
2. **同一服务器连接数上限** — IDM `226`/`1350`：dlm 现在只有全局 `--connections`，
   按 host 限可避免被拉黑
3. **完成后休眠** — IDM `21155`：dlm 有 `shutdown` 但没有 `hibernate`，`actions.rs` 加一档即可

### 缺，且与 UI 形状绑定（重写时顺带补最省）

| IDM 能力 | dlm 现状 | 差什么 |
|---|---|---|
| 继续 / 停止 | 部分 | 队列有；扩展与直连路径没有 |
| 全部停止 | 无 | 只有单任务 |
| 删除全部 | 无 | 只有单个删除 |
| 选项 | 部分 | 只有命令行参数 |
| 计划任务 | 部分 | 有 `start_at` 与配额窗口；无定时停/拨号/关机 |
| 开始队列 / 停止队列 | 无 | 无队列级启停 |
| 速度 / 剩余时间列 | 无 | `TaskView` 无速度与 ETA 字段 |

### 缺，但不是 UI 形状（recon 判"值得做"）

多镜像 `Url0..N`、代理与 PAC、阻止休眠、剪贴板捕获、队列优先级、
页面 fetch/XHR 挂钩、会话级 DNR 重定向与 `captured.html` 退回页。

### 明确不做（recon P2，每条有理由）

内核驱动（需微软签名）、站点接管规则库（是运营不是代码）、
WebGrabber 镜像/直播录制/DASH 合流、完整性级别绕行。

## 五之二、设置面板（原生 UI 的一部分）

D9 要求剪贴板监视可关，所以原生 UI 需要一个设置面板。最小集：

| 分组 | 项 | 默认 | 说明 |
|---|---|---|---|
| 下载 | 默认连接数 | 8 | 对齐 IDM `1350` |
| 下载 | 同一服务器最大连接数 | 8 | 新增；防被拉黑（IDM `226`） |
| 下载 | 默认保存目录 | `Downloads` | — |
| 下载 | 全局限速 | 关 | 对齐 IDM `337` |
| 行为 | **监视剪贴板** | **关** | 见下方判断 |
| 行为 | 完成后 | 无 / 打开 / 运行 / 关机 / **休眠** | 休眠为新增 |
| 行为 | 开机自启 | 关 | 已有 `--autostart` |
| 界面 | 关闭时收进托盘 | 开 | P1 |
| 界面 | 界面语言 | 跟随系统 | 本轮只做中文，字段先留 |

**剪贴板监视默认关，是我按隐私定的，不是 IDM 的做法**（IDM 默认开）。
理由：剪贴板里会有密码、验证码、私钥。一个默认开着的程序读剪贴板，
用户通常不知道。开启时给一句说明，讲清它只匹配"看起来像下载链接"的文本。
你不同意就改回默认开。
