# A1 `If-Range` 条件续传 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**状态**：已交付（2026-10-21；四闸 246/3/100/clippy 0）。

**Goal:** 续传的每一条窗口请求带 `If-Range`；对端回 `200` 时判"验证器变了"，不写一个字节，保留文件与断点。

**Architecture:** 断点快照里的 `Validator` 先经 `Plan` 传进 `Engine`，引擎按"强 ETag 优先、Last-Modified 仅在未开 `--ignore-mtime` 时用"算出一个固定值，交给每条 worker。`fetch` 新增一个带 `if_range` 的入口；原 `run_window` 保留为 `None` 包装，避免改掉三十多处既有调用。`200 + 发过 If-Range` 走 `Failed(ValidatorChanged)`，与退化 200 分开。

**Tech Stack:** Rust 2024、reqwest blocking、现有 `tests/harness`（node 对端＋Rust scripted peer）。

**Spec:** [`../specs/2026-10-15-dlm-kernel-design.md`](../specs/2026-10-15-dlm-kernel-design.md) §10 **R17**（本计划的上游；R9 的"不发 If-Range"半句已作废）。

在 `resume.rs` 的 `decide` 之前加：

```rust
/// 这一轮续传该发的 `If-Range` 值；`None` = 不发（退回探针先比、窗口照常的旧路径）。
///
/// 强 ETag 优先：RFC 9110 的 If-Range 只接受强验证器，`W/"..."` 与不带引号的串都不发。
/// Last-Modified 只在本次**没开** `--ignore-mtime` 时用 —— 开了还发它，等于让对端按时间戳
/// 把"用户明确说可以忽略"的变化重新判成重来。
pub fn if_range_value(validator: &crate::state::Validator, ignore_mtime: bool) -> Option<String> {
    if let Some(etag) = validator.etag.as_deref() {
        let etag = etag.trim();
        if etag.len() >= 2 && etag.starts_with('"') && etag.ends_with('"') {
            return Some(etag.to_string());
        }
    }
    if !ignore_mtime {
        if let Some(lm) = validator.last_modified.as_deref() {
            let lm = lm.trim();
            if !lm.is_empty() {
                return Some(lm.to_string());
            }
        }
    }
    None
}
```

```rust
#[test]
fn a_resumed_run_fails_cleanly_when_if_range_gets_200_after_the_probe() -> anyhow::Result<()> {
    let total = 1024 * 1024u64;
    let (peer, base) = harness::spawn_scripted_peer(
        total, vec![harness::Shot::Honest, harness::Shot::IgnoresRange], harness::Shot::IgnoresRange,
    )?;
    let dir = harness::tmp_dir("a1-if-range-run")?;
    let t = Task {
        url: format!("{base}/blob"),
        dir: dir.path().to_path_buf(),
        name: Some("a1.bin".into()),
        ..harness::blank_task()
    };
    let target = t.target_path();
    std::fs::write(&target, [0u8])?;
    let validator = dlm::state::Validator {
        etag: Some("\"scripted-206\"".into()),
        last_modified: None,
        total_len: total,
        final_url: t.url.clone(),
        ignore_mtime: false,
    };
    let snap = dlm::state::Snapshot::from_task(
        &t, validator, vec![dlm::state::SegView { start: 0, end: 0 }],
    )?;
    let state_path = dlm::state::path_for(&target);
    dlm::state::save(&state_path, &snap)?;

    let rep = dlm::engine::run(&t, dlm::engine::Config {
        workers: 1,
        min_seg: dlm::consts::MIN_SEGMENT_BYTES,
        max_retries: Some(0),
        verify_sha256: None,
        force_fresh: false,
        on_tick: None,
    })?;
    assert!(!rep.ok, "验证器变了必须报未完成");
    assert!(rep.message.as_deref().unwrap_or("").contains("If-Range"), "文案要点名 If-Range：{:?}", rep.message);
    assert_eq!(std::fs::metadata(&target)?.len(), 1, "退化路径不许把 200 的 body 写到偏移 1");
    assert!(state_path.exists(), "断点必须保留");
    drop(peer);
    Ok(())
}
```
