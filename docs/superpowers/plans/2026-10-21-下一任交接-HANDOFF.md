## 四、具名欠账（"已登记"，不是"已修"，也不是遗漏）

- **端到端带凭据的成功路径本机买不到**：对端不做 TLS。已买到的是**错误支**活体针 `a_landing_url_carrying_the_wire_credential_pair_is_refused_on_the_error_branch_and_keeps_the_stage`（载体＝`--url https://127.0.0.1:<明文桩>/x/<blob>` ⇒ 握手必失败 ⇒ 那条串只活在 `e.url()` 里）。`fetch` 那四处只能靠源码文本针 `the_four_landing_ports_in_fetch_all_go_through_the_unified_criterion` 守"不分家＋不摘口令"，**它不证明四处真能拒**。
- **对面版本依赖两张表**：十条服务器 `Location` 实测表（`measure_the_landing_strings_reqwest_hands_back_for_server_supplied_locations`）与三臂剥头针，只在 **reqwest 0.13.5 / url 2.5.8 / tower-http 0.6.11 / http 1.5.0** 上成立 ⇒ 升级任一个**必须复量**（锁已入库，`cargo metadata --locked` 是复验入口）。
- **凭据内容判据的可见面**：只认"按标准编码/书写我们这份凭据"。看不见——对面二次百分号编码（只解一层）、`+` 当空格、大小写打乱、加盐、截断、base64 之后再百分号、顺序颠倒的 `base64("<口令>:<user>")`、引号包着的口令。**4 字节下限是文档化边界**（`PASSWORD_CONTENT_FLOOR`，按 UTF-8 字节；短于此两组都不比内容）。
- **第二组（解 base64 找 `:<口令>`）的代价**：误杀面不再只由字面撞中决定；每段 run × 4 相位 × 2 表的**线性**解码，长度由对端给，不设上限、**不拿墙钟做判据**。
- **放行路径上 reqwest 的错误文本会整条抄 URL**（已升成 README 具名边界 ④，反臂就是它的针），以及 `--cookie`／`--referer` 会原样进断点文件（用户裁"只补文档边界"，是设计）。
- **`--out-dir` 自身写成 `inner/..`** 时闸照放、落点被 OS 解析到字面目录之外（等价于父目录，非真越界，**待裁**，`#E33⑥③`）。

## 七、动手前的自检（我这一波反复撞的地方）

1. 想写"某形状不会造成危害／某一臂拿不到那个值"之前——**先拿真二进制或真函数走一遍那一格**，并 `grep` 自己的既有用例注释里有没有反面结论（我三次栽在"新写的裁定前提为假"）。
2. 想在简报里指定"用哪个标准库函数量这个形状"——先自己拿已知真值打一遍（`Path::components()` 会把 `.` 规范化掉，就是这类坑）。
3. 想放宽一条断言之前——先查它撞红的原因是不是**拍板**；本项目宁可改夹具入参，不动断言。
4. 想说"这一发买不到夹具"——那是可达性断言，**要证明**（我说过两次"买不到"，两次都被在同一台机器上打中）。
5. 改完任何一轮：四闸 ＋ `git status` ＋ `git diff --stat` 复核射程，然后**先写账、再提交**。
