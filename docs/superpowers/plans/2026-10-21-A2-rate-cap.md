# A2 全任务共享速率上限 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**状态**：已交付（2026-10-21；四闸 252/3/102/clippy 0）。

**Goal:** `--max-speed <BYTES_PER_SECOND>` 对所有网络连接**合计**生效；0 = 不限；探针预读、窗口请求、`--data-file` 整份请求都过同一只限速器。

**Architecture:** 新增 `rate::RateLimiter`（`Mutex<Instant>` 的漏桶，`reserve(now, bytes)` 返回等待时长、`consume` 睡眠）。`engine::run` 建一只 `Arc<RateLimiter>`，探针与所有 worker 共用；`--data-file` 那一路在 `run_whole_once` 里建一只。三条读取口在每次 `read` 返回后 `consume(n)`。

**Tech Stack:** Rust 2024、`std::sync::Mutex`、`Instant`、现有 harness。

**Spec:** [`../specs/2026-10-15-dlm-kernel-design.md`](../specs/2026-10-15-dlm-kernel-design.md) §10 **R18**。

## Global Constraints

- 四闸是 floor；不推送；不 `checkout`/`reset`/`stash`；报告先写、提交第二。
- 既有判据一条不许放宽；`--max-speed 0` 必须与今天逐字节等价（不睡眠、不改预算）。
- 限速器不拿墙钟做**判据**：单测用 `reserve(now, bytes)` 的注入时钟；集成层只测"总时长有下界"。
- 不新增依赖；限速不是配额，不做暂停/择时恢复。
- 速率上限是"所有读取合计"，不是"每条连接各一份"。

- [ ] **Step 3: 写实现**

```rust
use std::sync::Mutex;
use std::time::{Duration, Instant};

pub struct RateLimiter {
    bytes_per_second: u64,
    next: Mutex<Instant>,
}

impl RateLimiter {
    pub fn new(bytes_per_second: u64) -> Self {
        Self { bytes_per_second, next: Mutex::new(Instant::now()) }
    }

    /// 预约 `bytes` 个字节的发送时隙；返回调用方还需要等多久。
    /// 第一块立刻可用；之后每块按 `bytes / rate` 排到共享的 `next`。空闲不累计。
    pub fn reserve(&self, now: Instant, bytes: u64) -> Duration {
        if self.bytes_per_second == 0 || bytes == 0 {
            return Duration::ZERO;
        }
        let nanos = ((bytes as u128) * 1_000_000_000u128 / self.bytes_per_second as u128)
            .min(u64::MAX as u128) as u64;
        let spacing = Duration::from_nanos(nanos);
        let mut next = self.next.lock().expect("rate limiter 的锁没有别的持有者");
        let ready = (*next).max(now);
        *next = ready.checked_add(spacing).unwrap_or(ready + Duration::from_secs(3600));
        ready.saturating_duration_since(now)
    }

    pub fn consume(&self, bytes: u64) {
        let wait = self.reserve(Instant::now(), bytes);
        if !wait.is_zero() {
            std::thread::sleep(wait);
        }
    }
}
```

`src/lib.rs` 加 `pub mod rate;`。

`read_bounded` 改成循环读，**不用** `read_to_end`：

```rust
fn read_bounded(mut resp: Response, prelude_max: u64, limiter: Option<&RateLimiter>) -> Result<Vec<u8>> {
    let mut prelude = Vec::new();
    let mut buf = vec![0u8; 64 * 1024];
    let mut remaining = prelude_max;
    while remaining > 0 {
        let want = usize::try_from(remaining.min(buf.len() as u64)).expect("不超过缓冲");
        match resp.read(&mut buf[..want]) {
            Ok(0) => break,
            Ok(n) => {
                if let Some(l) = limiter { l.consume(n as u64); }
                prelude.extend_from_slice(&buf[..n]);
                remaining -= n as u64;
            }
            Err(e) => {
                return Err(anyhow::Error::new(e)
                    .context(format!("读预读体失败（对端在预读读完之前把连接断了？）已读到 {} 字节", prelude.len())));
            }
        }
    }
    Ok(prelude)
}
```

- [ ] **Step 1: 四 worker 共享上限**

⚠ **不要用 `harness::spawn_scripted_peer` 测多 worker**：它是单线程顺序服务，probe 之后会在同一条连接上
`read` 阻塞 10 s 等下一枪，其他 worker 的连接全排在它后面（本发实测把 2 MiB / 1 MiB/s 拖成 12.2 s，
限速器本身只排了 2.06 s）。用 node 对端的 `/sz/<字节数>` 路由。

```rust
#[test]
fn a_shared_rate_cap_spans_all_workers() -> anyhow::Result<()> {
    let total = 2 * 1024 * 1024u64;
    let (_srv, base) = harness::spawn()?;
    let dir = harness::tmp_dir("a2-shared-cap")?;
    let t = Task { url: format!("{base}/sz/{total}"), dir: dir.path().to_path_buf(), name: Some("a2.bin".into()), ..harness::blank_task() };
    let started = Instant::now();
    let rep = dlm::engine::run(&t, dlm::engine::Config {
        workers: 4,
        min_seg: dlm::consts::MIN_SEGMENT_BYTES,
        max_retries: Some(0),
        verify_sha256: Some(harness::expected_sha(total)),
        force_fresh: false,
        max_speed: 1_048_576,          // 1 MiB/s 合计
        on_tick: None,
    })?;
    let elapsed = started.elapsed();
    assert!(rep.ok, "{:?}", rep.message);
    assert_eq!(rep.delivered, total);
    assert!(elapsed >= Duration::from_millis(1500), "四连接各限一份会在这个下限之下：{elapsed:?}");
    Ok(())
}
```

（`Config` 字面量按实际字段顺序补；若用 `..Config::default()` 要显式覆盖 `max_speed`。）
