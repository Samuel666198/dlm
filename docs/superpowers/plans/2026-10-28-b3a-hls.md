## Task 1 解析与下载

- `src/hls.rs`：`looks_like?` 不需要；`run(task, cfg, started)`；`fetch_text`、`parse`、`download`。
- `src/lib.rs`：`pub mod hls;`。
- `engine::build_client` / `sha256_of_path` / `hash_matches` / `sha256_mismatch_message` 改成
  `pub(crate)` 复用。
- `consts::FLAG_HLS = 1 << 3`；`Cli.hls` / `--hls` 置位；`Task::hls()`；`report` 的 flags 摘要加 HLS。
- `engine::run` 在 probe 前分流 `task.hls()`；`main::finish` 对 HLS 不打印进度行前导换行。
- CLI 边界：`--hls` 与 `--data-file` / `--max-bytes` 互斥。

## Task 2 测试

- `hls::tests`：master 选最高带宽、相对 URI、拒绝 `#EXT-X-KEY`、默认输出名。
- `tests/integration.rs`：
  - `hls_downloads_master_playlist_segments_in_order`：node 对端 master → media → 三个分片；
    合并后逐字节等于 `alpha+beta+gamma`。
  - `hls_is_refused_with_data_file_or_max_bytes`：退 2、对端零请求。
  - `hls_rejects_encrypted_playlists`：`#EXT-X-KEY:METHOD=AES-128` ⇒ 退 1，报告“加密 HLS 不支持”。
- 四闸。
